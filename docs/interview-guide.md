# Interview guide

This portfolio project demonstrates a FastAPI service for SRE incident support. FastAPI gives typed validation and dependency injection. Cloud Run starts the OCI container and supplies a service identity; ADC lets `google-genai` access Vertex AI without API keys. Liveness proves process health; readiness proves initialization/configuration. Middleware logs JSON with request IDs and optional Cloud trace context. Bounded exponential backoff retries only transient upstream failures. Monitoring uses Cloud Run metrics and alerts. GitHub Actions uses Workload Identity Federation, separating deploy and runtime identities. IAM investigations begin with structured logs, service-account policy, and Vertex permissions; timeout investigations compare latency, retry, and quota evidence. Local tests use mocked Vertex calls. Cloud deployment and real Vertex inference remain unverified until performed using authorized credentials. Future work: durable event storage, authenticated dashboard, distributed tracing, and SLO-based alerting.
